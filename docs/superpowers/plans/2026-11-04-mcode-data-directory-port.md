**Goal:** Build inactive, bounded per-root credential-source acquisition and compact absence accounting without claiming complete inventory or start authority.
**Architecture:** An immutable root-scoped policy and audited path map feed discovery checkpoints and independent root helpers. Each root helper captures and parses two passes in private memory; the coordinator brackets sorted root rounds with discovery and returns diagnostics only. Existing strict frozen-rootfs and collector contracts stay unchanged.
**Tech Stack:** Python3.12 stdlib, existing pinned PyYAML6.0.3, existing bounded command transport and pure MiniMax parsers. No new dependency/global installation.
**Spec:** docs/superpowers/specs/2026-11-04-mcode-data-directory-port-design.md, Rad-approved revision4ae68fb (4November2026).
